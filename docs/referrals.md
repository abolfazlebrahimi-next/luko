# معرفی دوستان در پنل والدین

هر والد یک لینک تصادفی ثابت دارد؛ در نسخه CRA از «تنظیمات ← دعوت دوستان» کپی می‌شود. فقط ایجاد حساب والد جدید با OTP تأییدشده از همین لینک باعث ثبت معرفی و دو اعتبار سه‌روزه می‌شود. حساب قبلی، کد نامعتبر، شمارهٔ خود معرف، ورود مجدد و ورود دانش‌آموز پاداش ندارند. کد نامعتبر مانع ورود نیست. لینک در جابه‌جایی بین صفحات ورود و ثبت‌نام باقی می‌ماند.

اولین خرید واقعی و تأییدشدهٔ فرد معرفی‌شده، یک اعتبار ۱۵ روزه به معرف می‌دهد؛ هدیه، پرداخت ناموفق و تکرار callback یا بازیابی خرید بازار پاداش دیگری ایجاد نمی‌کنند. اعتبار تا انتخاب فرزند فعال از سوی صاحب اعتبار مصرف نمی‌شود؛ بدون فرزند نیز باقی می‌ماند. برای فرزند دارای اشتراک همیشگی نمی‌توان آن را مصرف کرد. اعتبار مصرف‌شده به شکل یک پرداخت هدیه به انتهای اشتراک موجود اضافه می‌شود.

API والد: `GET /api/v1/parent/referral` و `POST /api/v1/parent/referral/rewards/{id}/redeem` با `childId`. احراز هویت و مالکیت اعتبار و پیوند فعال فرزند سمت سرور بررسی می‌شوند. پس از استقرار باید migrationهای Django اجرا شوند. لینک از origin فعلی فرانت ساخته می‌شود؛ دامنه باید مسیرهای SPA و API را پشتیبانی کند.

محدودیت‌های عملیاتی: اعتبارها و معرفی‌ها برای حسابداری نگهداری می‌شوند؛ این سیستم جلوی ایجاد حساب‌های مختلف با شماره‌های واقعی متعدد را نمی‌گیرد. بررسی ضدتقلب، سیاست بازگشت وجه و بازپس‌گیری پاداش و سیاست‌های نگهداری داده باید پیش از انتشار نهایی تعیین شوند. در `frontend-cra` مسیر خرید اشتراک مستقل موجود نیست؛ اتصال اعطای پاداش به مسیرهای پرداخت موجود بک‌اند انجام شده است.
